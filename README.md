# ServiceNow Service Portal Widget Library

A reference collection of reusable ServiceNow Service Portal widgets, UI patterns, and examples for learning, prototyping, and solution design.

> **Repository context**  
> This repository is based on the ServiceNow Innovation Library / Platform Experience widget collection. It is retained here as a technical reference and learning resource rather than presented as wholly original work.

![Widget Library](images/il-hero.jpg)

## What you will find

The repository contains examples covering common Service Portal requirements such as cards, charts, approvals, HR experiences, navigation patterns, notifications, and other reusable widgets.

## Typical uses

- Review proven Service Portal implementation patterns.
- Prototype portal experiences before adapting them to a customer application.
- Study widget structure across HTML, client, server, CSS, and options.
- Compare approaches for data visualisation and interactive components.

## Repository structure

Each top-level widget or category contains the assets required for that example. Supporting material is available under `docs/` and `images/`.

## Using the examples

Service Portal customisations should be validated against the ServiceNow release and portal architecture used by the target instance. Review server-side access, ACLs, dependencies, and upgrade implications before using any example in production.
